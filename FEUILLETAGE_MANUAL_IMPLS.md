# Feuilletage Projection Completion

The Omni config tree has no manual `feuilletage::FromContextValue`
implementations. All 17 implementations tracked by the earlier inventory are
now generated by `#[derive(feuilletage::Config)]` projections.

## Converted Types

- `UpConfigBash`
- `UpConfigNodejs`
- `UpConfigPython`
- `AssetNameMatcher`
- `CommandSyntax`
- `UpConfigHomebrew`
- `UpConfig`

## Current Pattern

Complex input shapes are represented by typed wire schemas. The domain type
uses `#[feuilletage(parse_as = "...")]`, and its `FromParsed` implementation
performs semantic conversion, normalization, runtime enrichment, and
recoverable diagnostic handling. This keeps Feuilletage responsible for
projection and validation without forcing domain behavior into dynamic parsing
code.

`StoredConfig` is the only intentional exception to typed wire projection. It
projects through `feuilletage::Value` because arbitrary suggestion config must
be retained while context and provenance are stripped from the stored value.

Projection `MutabilityInfo` delegates to the wire schema's constraints, so
level mutability remains defined by the parsed representation. Serialization
shape and diagnostic behavior are covered by parity tests.
